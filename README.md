# 📊 AtliQ Hardware Sales Dashboard

An interactive sales analytics dashboard built using **Microsoft Power BI** as part of a Codebasics project, focused on analyzing sales performance and generating meaningful business insights for AtliQ Hardware.

## 📌 Project Overview

This project focuses on analyzing sales data for AtliQ Hardware using Power BI to understand sales trends, evaluate business performance, and support data-driven decision-making through interactive visualizations and key performance indicators.

## 📈 Dashboard Features

- Key Performance Indicators (KPIs)
- Interactive charts and visualizations
- Data filtering and slicers
- Sales trend analysis
- Customer and product performance analysis
- Revenue and sales performance insights
- Data-driven business insights

## 🛠️ Tools & Technologies

- Microsoft Power BI Desktop
- Power Query
- DAX
- Data Modeling
- Data Visualization

## 🚀 How to Use

1. Open the live dashboard using the link below.
2. Explore the interactive visualizations and sales metrics.
3. Use the available filters and slicers to analyze different aspects of the business.
